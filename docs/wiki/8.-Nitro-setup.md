# Nitro and Flash clients

## Nitro

Install the Nitro client assets under `public/` or on a trusted HTTPS asset host. In Housekeeping's CMS settings, set **`nitro_path`** to the directory containing Nitro's `index.html`, without appending the filename. Atom adds `/index.html?sso=...` when opening the client; this URL carries a login ticket, so only use a host you control and trust.

Ensure Nitro's `renderer-config.json` and `ui-config.json` references resolve from the chosen directory. A leading `/` points to the host root; a relative reference stays under the client directory. Configure the client and emulator endpoints for your own installation, and use HTTPS-compatible asset and socket URLs when the hotel uses HTTPS.

Set `CLIENT_NITRO_ENABLED=true` for Nitro badge external-texts support. The `nitro_path` database setting is the path used by the bundled theme iframe; older instructions referring to `nitro_client_path` are obsolete.

## Flash

Existing Flash support remains available through the Flash route. Set `FLASH_CLIENT_ENABLED=true` to expose the Flash option in navigation, and configure the `EMULATOR_*`, `SWF_BASE_PATH`, `HABBO_SWF`, `PRODUCTION_FOLDER` and `EXTERNAL_*` variables documented in `.env.example` for your compatible client environment.

For badge management to maintain Flash external texts, also set `CLIENT_FLASH_ENABLED=true` and `CLIENT_FLASH_FILES_PATH` to the client directory relative to `public/`. Keep write permissions limited to the configured external-texts files and any directories required for their updates.

Older client setup walkthroughs are linked from [installation](1.-Installing-Atom-CMS.md#troubleshooting); their PHP and CMS installation steps predate this release.
