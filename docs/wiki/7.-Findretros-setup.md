# FindRetros setup

Set your hotel's FindRetros name in `.env`:

```dotenv
FINDRETROS_NAME=your-findretros-name
FINDRETROS_ENABLED=true
```

Refresh cached configuration after changing these values. Check the vote flow with a normal user account and confirm it returns to the hotel after voting.

If an HTTPS request fails with cURL error 60, repair the PHP CA bundle using [the installation troubleshooting guide](1.-Installing-Atom-CMS.md#troubleshooting). Keep TLS certificate verification enabled.
