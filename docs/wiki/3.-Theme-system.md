# Theme system

Themes live in `resources/themes/`. Atom ships `atom` and `dusk`; missing views can fall back to the parent theme configured in `config/theme.php`.

Build the target theme before changing the `theme` value through Housekeeping's CMS settings:

```bash
npm ci
npm run build:atom
npm run build:dusk
```

Build both when both themes must remain available. `php artisan build:theme` offers an interactive selection. During development use `npm run dev:atom` or `npm run dev:dusk`.

To scaffold a custom theme:

```bash
php artisan make:theme my-theme
```

The command comes from the installed `qirolab/laravel-themer` package. Review its generated files and add the `dev:my-theme` and `build:my-theme` scripts it prints to `package.json`. Follow the bundled Vite configuration for asset paths and manifests. Decline replacement authentication scaffolding unless replacing that integration is intentional; Atom's existing authentication and controllers support the hotel's features.

Build the custom theme, set its directory name as the CMS `theme`, and check the login, registration, user settings, client, shop and housekeeping flows. Use the shared [settings guidance](README.md#changing-settings) when making database changes outside Housekeeping.
