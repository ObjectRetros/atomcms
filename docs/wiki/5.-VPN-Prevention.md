# VPN and IP restrictions

To enable IP reputation checks on the client routes, set `vpn_block_enabled=1` and a valid `ipdata_api_key` in Housekeeping's CMS settings. Obtain the key from your [ipdata account](https://dashboard.ipdata.co/).

Manual lists use `website_ip_whitelist` and `website_ip_blacklist`. Entries identify an `ip_address`, or an `asn` with the corresponding `whitelist_asn` / `blacklist_asn` flag. The `bypass_vpn` permission in `website_permissions` controls the minimum staff rank that skips these checks.

The middleware checks an explicit IP allowlist or staff bypass first, then an explicit IP blocklist, then ASN allow/block lists and IP reputation. An ASN allowlist does not override an explicit IP block. Failed reputation lookups allow the request and are cached briefly; this feature is not a guarantee that every VPN is blocked.

Configure trusted proxies as described in [deployment](1.-Installing-Atom-CMS.md#production-configuration) so checks use the visitor's address. Developers can apply the `vpn.checker` middleware to additional routes in `routes/web.php` when those routes require the same behavior.
