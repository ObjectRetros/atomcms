# Bot protection

Atom supports Cloudflare Turnstile and Google reCAPTCHA v2. Configure one provider at a time, with the other disabled in CMS settings.

## Cloudflare Turnstile

Create a widget for the hotel's hostname in the [Turnstile dashboard](https://dash.cloudflare.com/), then set:

```dotenv
TURNSTILE_SITE_KEY=your-site-key
TURNSTILE_SECRET_KEY=your-secret-key
```

Set `cloudflare_turnstile_enabled=1` and `google_recaptcha_enabled=0` in `website_settings` through Housekeeping. Keep the secret key private.

## Google reCAPTCHA

Register the hostname in the [Google reCAPTCHA console](https://www.google.com/recaptcha/admin/) using **reCAPTCHA v2, “I'm not a robot” Checkbox**. Set:

```dotenv
GOOGLE_RECAPTCHA_SITE_KEY=your-site-key
GOOGLE_RECAPTCHA_SECRET_KEY=your-secret-key
```

Set `google_recaptcha_enabled=1` and `cloudflare_turnstile_enabled=0` in CMS settings.

Rebuild cached environment configuration after editing `.env`. Check login and registration in a signed-out browser: a valid challenge should submit successfully, and a missing or invalid challenge should be rejected. Ensure the selected theme loads the provider's script; Cloudflare Rocket Loader must be disabled for Atom.
