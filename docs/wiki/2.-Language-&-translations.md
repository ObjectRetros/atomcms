# Language and translations

Set the default locale in `.env`, using an existing filename from `lang/`:

```dotenv
APP_LOCALE=da
```

Rebuild cached configuration with `php artisan config:cache` in production, or clear it with `php artisan config:clear` during development. A user's saved language selection takes precedence over the default.

To add a language, copy `lang/en.json` to a new locale filename and translate the values, keeping the English keys and placeholders intact. Existing locale names such as `br` and `se` are part of Atom's current support; use the matching filename rather than renaming them during an update.

```json
{
    "Home": "Hjem",
    "Community": "Fællesskab",
    "Shop": "Butik"
}
```

Add the matching `country_code` and display `language` to `website_languages` so it appears in the selector. Update `WebsiteLanguageSeeder` when contributing a bundled language. Wrap new Blade text with `{{ __('Your text') }}` and add its translation to the JSON files. See [Laravel 13 localization](https://laravel.com/docs/13.x/localization#using-translation-strings-as-keys).
