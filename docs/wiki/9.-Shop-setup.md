# Shop and PayPal setup

Atom's shop sells website balance through PayPal and spends that balance on configured shop items/packages. Fulfillment depends on the selected emulator's supported capabilities.

## Sandbox

Create a sandbox REST app in the [PayPal Developer Dashboard](https://developer.paypal.com/dashboard/applications/sandbox) and configure:

```dotenv
PAYPAL_MODE=sandbox
PAYPAL_CURRENCY=USD
PAYPAL_SANDBOX_CLIENT_ID=your-sandbox-client-id
PAYPAL_SANDBOX_CLIENT_SECRET=your-sandbox-client-secret
PAYPAL_WEBHOOK_ID=your-sandbox-webhook-id
```

On that same PayPal app, register your publicly reachable HTTPS endpoint `https://hotel.example/api/paypal/webhook` for **CHECKOUT.ORDER.APPROVED** and **PAYMENT.CAPTURE.COMPLETED**. Put the webhook's ID, not its URL, in `PAYPAL_WEBHOOK_ID`. `PAYPAL_NOTIFY_URL` does not register the webhook or replace that ID. Atom verifies webhook signatures and checks the captured payment before crediting a user. See [PayPal's webhook documentation](https://developer.paypal.com/api/rest/webhooks/).

Run `php artisan config:cache` after changing production-style cached configuration. Configure the [Laravel scheduler](1.-Installing-Atom-CMS.md#scheduler-and-queues): Atom reconciles pending PayPal orders every five minutes, including when the browser never reaches the success page. `php artisan paypal:reconcile --limit=100` runs reconciliation manually; it can capture approved real orders when configured in live mode.

Use a sandbox buyer to complete checkout, confirm the expected website balance is credited once, and confirm replaying the success URL or webhook does not credit it again. Also test canceling checkout and fulfillment of the items/packages offered by your emulator before accepting live payments.

## Live mode

Use the credentials for your live PayPal app:

```dotenv
PAYPAL_MODE=live
PAYPAL_LIVE_CLIENT_ID=your-live-client-id
PAYPAL_LIVE_CLIENT_SECRET=your-live-client-secret
PAYPAL_WEBHOOK_ID=your-live-webhook-id
```

Register the same event types and the production HTTPS endpoint on the live app. Sandbox and live credentials/webhook IDs are separate. Rebuild configuration after switching. Keep client secrets in `.env` or your deployment secret store and TLS verification enabled; Atom does not offer a `PAYPAL_VALIDATE_SSL` override.

Set `PAYPAL_CURRENCY` to a currency supported by your PayPal account and configure shop prices consistently. Review pending orders before changing currency so their recorded amount/currency remains understandable during reconciliation.

The previous wiki's PayPal setup guide was contributed by Puffin; this version reflects Atom's verified webhook and reconciliation flow.
