# Atom CMS documentation

Atom CMS runs on PHP 8.5+, Laravel 13, Livewire 4, Filament 5, Vite and Tailwind CSS 4. It supports Arcturus Morningstar and Ada through emulator drivers, with Atom and Dusk themes.

Start with [installation](1.-Installing-Atom-CMS.md), then configure your [theme](3.-Theme-system.md), [language](2.-Language-%26-translations.md), [client](8.-Nitro-setup.md) and [shop](9.-Shop-setup.md). The [documentation index](README.md) lists every guide.

Use [Laravel 13 documentation](https://laravel.com/docs/13.x) for framework behavior and [Laravel Learn](https://learn.laravel.com) for learning materials. Project-specific setup and supported emulator behavior are documented here.
