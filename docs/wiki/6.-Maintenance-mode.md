# Maintenance mode

Set `maintenance_enabled=1` through Housekeeping's CMS settings to show Atom's maintenance page. `min_maintenance_login_rank` sets the minimum rank allowed through; eligible staff can still sign in. Set `maintenance_message` to the message visitors should see.

The `website_maintenance_tasks` table contains optional progress entries: `user_id` identifies the assignee, `task` describes the work, and `completed` controls the completion indicator. Set `maintenance_enabled=0` to reopen the hotel.

Laravel's `php artisan down` and `php artisan up` provide a separate deployment maintenance mode that runs before Atom's page and staff checks. Use it for application updates as described in [deployment](1.-Installing-Atom-CMS.md#updating-an-installed-hotel). Atom's staff rank bypass does not bypass Laravel's maintenance response.
